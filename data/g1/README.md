# G1協力データ（2021〜2025）

共有されたGoogle Driveフォルダ `UMA_DB_G1_20210504-20260903` から、2021〜2025年の行だけを取り込んだメタデータです。

- `entry_sheet.csv`: 予測対象の出馬表。結果列は含めない
- `result_sheet.csv`: 評価専用の確定着順
- `processing_summary.csv`: 元データ加工時の件数と条件欠損

馬・騎手の履歴CSVは合計約1.4GBになるため追跡しません。`scripts/generate_g1_demo.py` は、元フォルダ内の `race_<レースID>/horse_history.csv` と `jockey_history.csv` を直接読み、次を行います。

1. 対象レース日と同日または未来の行を除外
2. 同じ主体・日付・開催・R・距離・タイムの重複を除外
3. 各馬または各騎手の直近40走に制限
4. 2025年の各レースを時点順に独立予測

出典URLはCSV内に保持しています。ID列は文字列として扱い、特に騎手IDの先頭ゼロを落とさないでください。オッズ取得時刻は記録されていないため、表示される期待回収率は過去検証の参考値です。
