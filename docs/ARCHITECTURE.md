# 設計と確率の整合性

観測速度を `v(h, r) = b(r) + f_h(r) + ε` と分解します。`b(r)` は全馬の過去走を共有するレース条件別基準速度、`f_h(r)` は馬固有の残差ガウス過程です。入力条件は競馬場、芝・ダート、距離、馬場状態です。

- 基準速度は正則化線形モデルで、未知カテゴリでも距離項と切片へ退避します。
- 3走以上は距離RBFとカテゴリ一致度を組み合わせた残差GP、3走未満は馬の平均残差を母集団平均0へ縮約します。
- API境界で `occurred_at < prediction_at` だけを抽出し、予測対象と同時刻以降の情報を学習から除外します。

各馬の予測速度分布から同じ乱数標本で全馬の速度を引き、標本ごとに一意の着順を作ります。そのため単勝・三連複・三連単の各確率総和は1となり、ある三連複の確率は対応する6通りの三連単確率の和になります。

期待回収率は `的中確率 × 券種・買い目そのものの確定オッズ` です。単勝オッズを三連系へ合成せず、該当オッズがない行は `null` を返します。
