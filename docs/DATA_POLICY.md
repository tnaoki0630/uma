# データ取得・運用ポリシー

このリポジトリは外部サイトの自動取得を本番経路に含めません。既存の `src/makeCSV*.py` は研究用の旧コードとして残していますが、対象サイトの利用規約、robots.txt、データライセンス、アクセス頻度を確認せず実行しないでください。規約で自動取得が認められない場合は、JRA-VAN Data Lab.など利用許諾の明確なデータ提供元、または利用者が適法に取得したCSVを使います。

本番パイプラインでは取得元、取得時刻、発走時刻、オッズ時点、スキーマ版、モデル版を保存します。予測スナップショットは発走前に固定し、確定着順・確定タイム・払戻・発走後オッズを特徴量へ混ぜません。検証分割はランダムではなく日付順のウォークフォワード方式にします。

APIキーや契約データはGitHub Pagesやリポジトリへ置かず、APIホスティング側のSecretとして管理します。

`src/makeCSV.py --type 3` は騎手リーディングと各騎手の近走ページを順番に取得します。自動取得を実行する前に最新の利用条件を確認してください。`--number` と `--upperbound` を必要最小限にし、短時間の反復実行や並列アクセスを避けます。
